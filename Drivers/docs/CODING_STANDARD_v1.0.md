# 1. مقدمه

این سند، مرجع رسمی توسعه نرم‌افزار پروژه **Dual Voltage Monitor** است.

هدف از تهیه این سند، ایجاد یک استاندارد واحد برای طراحی، پیاده‌سازی، مستندسازی و نگهداری نرم‌افزار پروژه است.

تمام فایل‌های پروژه، اعم از Driver، Service، Application، Menu، Display، Configuration و سایر ماژول‌ها، باید مطابق قوانین این سند توسعه داده شوند.

این سند صرفاً مجموعه‌ای از قوانین برنامه‌نویسی نیست؛ بلکه فلسفه طراحی نرم‌افزار پروژه را نیز مشخص می‌کند.

این پروژه تنها با هدف ساخت یک دستگاه اندازه‌گیری ولتاژ ایجاد نشده است.

هدف اصلی، تولید یک نرم‌افزار Embedded است که دارای ویژگی‌های زیر باشد:

- معماری شفاف و قابل توسعه
- مستندسازی کامل
- قابلیت نگهداری در بلندمدت
- استقلال ماژول‌ها
- قابلیت استفاده مجدد از ماژول‌ها
- کیفیت مناسب برای انتشار عمومی

کد باید به گونه‌ای نوشته شود که حتی چند سال بعد نیز بدون نیاز به توضیح شفاهی، قابل درک و قابل توسعه باشد.
