# معماری سیستم منو
## Part 1

# 1- مقدمه

سیستم منوی پروژه Dual Voltage Monitor رابط بین کاربر و امکانات داخلی دستگاه است.

اهداف:
- سادگی استفاده
- توسعه‌پذیری
- جداسازی منطق از سخت‌افزار
- جلوگیری از ورود تنظیمات نامعتبر

## وظایف لایه‌ها

### Button Application
- دریافت رخداد کلیدها
- تبدیل به رویدادهای منطقی

مثال:

Physical Button Press

↓

BUTTON_ENTER_EVENT

### Menu Controller

مسئول:
- حرکت بین منوها
- ورود به زیرمنو
- خروج از زیرمنو
- مدیریت حالت ویرایش

### Menu Renderer

مسئول:
- نمایش عنوان
- نمایش مقادیر
- نمایش وضعیت‌ها

### LCD Driver

توابع نمونه:

LCD_Clear()
LCD_SetCursor()
LCD_Print()

# 5- فلسفه طراحی

- گزینه‌های پرکاربرد در ابتدای منو قرار گرفته‌اند.
- تنظیمات در گروه‌های مستقل دسته‌بندی شده‌اند.
- عملیات خطرناک داخل Service Mode قرار دارد.
- هر صفحه فقط یک وظیفه دارد.

# 6- صفحه Live Monitor

نمایش:

    Voltage Monitor

    Vin : 218.5 V
    Vout: 223.5 V

    Alarm: OFF   NORMAL

قوانین وضعیت:

- اگر Vout < Low Voltage Limit → LOW VOLT
- اگر Vout > High Voltage Limit → HIGH VOLT
- در غیر این صورت → NORMAL

نکته:
نمایش NORMAL / LOW VOLT / HIGH VOLT مستقل از Alarm Enable است.

# 7- صفحه Start Stream

    Streaming N=1034

    Rate : 500 ms

    Time : 00:12:34

    221.5  214.7  NORMAL

توضیحات:

N :
تعداد نمونه‌های ارسال شده.

Rate :
از مقدار ذخیره شده Sample Rate خوانده می‌شود.

Time :
از لحظه شروع Stream محاسبه می‌شود.

====================================================================

تمام پارامترها دوباره بررسی می شوند.

Low Voltage < High Voltage

------------------------------------------------

Low Volt must be

lower than High Volt

BACK:Return
------------------------------------------------



در این حالت:


• هیچ مقداری ذخیره نمی شود.

• کاربر به صفحه تنظیمات بازگردانده می شود.

• تنظیمات قبلی بدون تغییر باقی می مانند.

# 10- Calibration


هدف بخش Calibration تنظیم دقیق اندازه گیری ولتاژ ورودی و خروجی
بر اساس یک ولتاژ مرجع واقعی است.

در این پروژه از روش Wizard استفاده می شود تا کاربر بدون نیاز
به وارد کردن دستی Offset بتواند دستگاه را کالیبره کند.



ساختار منو:


MAIN MENU
    |
    +-- Calibration
            |
            +-- Input Voltage Calibration
            |
            +-- Output Voltage Calibration



====================================================================
فلسفه طراحی
====================================================================


دو روش برای کالیبراسیون وجود دارد.


روش اول

تنظیم مستقیم Offset



مزایا:

• ساده برای برنامه نویسی


معایب:

• نیاز به دانش فنی کاربر

• احتمال ورود مقدار اشتباه

• مناسب کاربران سرویس نیست



------------------------------------------------------------


روش دوم

Calibration Wizard

• کاربر فقط یک ولتاژ مرجع در اختیار دارد.

• Offset توسط نرم افزار محاسبه می شود.

• احتمال خطای انسانی بسیار کمتر است.

• رابط کاربری حرفه ای تر خواهد بود.



در این پروژه روش دوم انتخاب شده است.

این ساختار باعث می شود Service Mode در آینده بدون تغییر
معماری اصلی نرم افزار توسعه پیدا کند.

نرم افزار را بر عهده دارد.

قابل ویرایش نمی باشد.
