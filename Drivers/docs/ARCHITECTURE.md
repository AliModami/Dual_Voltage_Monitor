# 1- فلسفه طراحی پروژه

-------------------------------------------------------------------------------

این پروژه صرفاً یک مدار اندازه‌گیری ولتاژ نیست.

هدف، ساخت یک Embedded Framework حرفه‌ای است که بتوان
بخش‌های مختلف آن را در پروژه‌های آینده نیز استفاده کرد.

بنابراین:

• هر ماژول فقط یک مسئولیت دارد.

• وابستگی بین ماژول‌ها باید حداقل باشد.

• هیچ ماژولی نباید جزئیات داخلی ماژول دیگر را بداند.

• توسعه آینده نباید باعث بازنویسی گسترده کد شود.



# 2- اصول طراحی

-------------------------------------------------------------------------------

این پروژه بر اساس اصول زیر طراحی می‌شود.


## اصل اول

Single Responsibility Principle


هر فایل فقط یک مسئولیت دارد.


مثال:

buttons.c

↓

فقط مدیریت کلیدها


و نه:

LCD

Menu

ADC



------------------------------------------------------------


## اصل دوم

Loose Coupling


وابستگی بین ماژول‌ها باید حداقل باشد.



------------------------------------------------------------


## اصل سوم

High Cohesion


توابع مرتبط باید داخل یک ماژول قرار بگیرند.



------------------------------------------------------------


## اصل چهارم

Hardware Abstraction


منطق برنامه نباید مستقیماً با سخت‌افزار کار کند.



مثال:


Menu

↓

Display

↓

LCD Driver

↓

HAL

↓

STM32



نه:


Menu

↓

LCD Driver

هیچ ماژولی اجازه ندارد وابستگی معکوس ایجاد کند.

# 5- قوانین Include

-------------------------------------------------------------------------------

هر ماژول فقط Header مورد نیاز خودش را Include می‌کند.

استفاده از Include های غیرضروری ممنوع است.

Circular Dependency ممنوع است.



# 6- طراحی Framework ها

-------------------------------------------------------------------------------

• Display Framework

• Menu Framework

• Button Framework

• ADC Framework

• Relay Framework

• Config Framework

• Logger Framework



# 7- قوانین توسعه

-------------------------------------------------------------------------------

۳- API چیست؟

۴- وابستگی‌ها چیست؟

۵- چگونه تست خواهد شد؟
